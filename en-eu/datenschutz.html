General

Calculations take place locally on the device. Calculator inputs are not automatically transmitted to the operator. No registration or sign-in is required. When the website is loaded, however, technically necessary connection data is processed by the hosting provider (Cloudflare, Inc.). See the "Hosting" section below for details. The operator does not perform any personal evaluation of these connection data.

The descriptions of browser storage, the Service Worker, hosting and country-based redirects refer to the website and installed PWA. Local storage and export in the native iOS app are described in the "Native iOS App" section.

Local Data Storage

Current storage. Calculator inputs (consumption, prices, mileage) are by default held only in the memory of the open page and discarded when you close or reload it. A history entry with an optional note is created only when you explicitly save it; it is kept locally in the browser and can be removed individually. Settings such as market, theme or history period are stored only after your explicit choice. A one-minute guard against double saving is kept in memory only. No additional automatic copy of the note is created. These contents are not automatically transmitted to the operator.

Voluntarily enabled storage. Only if you explicitly enable "Remember inputs on this device" is the input draft (without the note) stored in the browser's LocalStorage. While the option is off, existing remembered inputs are not loaded automatically; they are offered for loading or deletion. Switching the option off does not delete them; "Delete remembered inputs" (two steps) does.

Possible legacy data. Earlier versions could store inputs automatically (keys eaf.inputs, eaf.inputs.v1, eaf.inputs.v2) and write markers for the start animation, a visit counter for the install prompt and a timestamp lastSaveTime. These functions no longer exist; the current version neither writes nor reads those values. Existing legacy data is not deleted or converted without your say-so. Old input stores (eaf.inputs, eaf.inputs.v1) can be exported or deleted in the calculator interface; other legacy values can be removed through the browser's site data. Browser data can also be cleared by the browser itself.

When you share a calculation or export the history, contents may reach a recipient or storage location you choose as text, an image or a file. A history backup also includes saved notes. This is an action you initiate.

There is no start animation and no visit counter any more. The install help is an instruction page you open yourself via "Install app (instructions)"; no choice is stored for it.

Native iOS App

The native iOS app loads its bundled pages and resources locally in a WebView. Saved calculations, notes and settings are held in local WebView storage in the app container, separately from the browser's website data. Starting these local contents does not use the website's hosting, Service Worker or country-based redirect. External links and sharing destinations you choose may use network connections.

Imported JSON backups are processed locally. For a JSON or CSV export, the app writes a temporary file to its cache directory (CACHE) and opens the native share dialog. You choose the recipient or storage location. After the sharing attempt, the app tries to delete its temporary file. If cleanup is interrupted or fails, the file may remain. Copies already shared or saved elsewhere are not removed by this cleanup or by deleting the app's history.

Service Worker / Offline Cache

The website can use a Service Worker at your explicit request, a standardised browser feature that caches HTML pages and static resources (CSS, JavaScript, fonts, images) in the user's browser. The purpose is availability of the app without an active internet connection. Offline mode is voluntary: a Service Worker is registered only after your action "Make available offline"; without it the website registers none when loaded.

After activation, pages and static resources may be stored in the browser's cache. Identifiers of history links (fragment or the parameters id, entryKey, entryIndex) are not stored in cache keys. Calculator inputs and notes are not written to the cache. "Remove offline mode" removes the registration and this website's caches; caches of other applications are left untouched. A Service Worker registered automatically by an earlier version, and its cache, may continue to exist until you remove it this way or through the browser's site data.

Clearing this cache alone removes cached pages and resources. Clearing all website data may also delete localStorage containing saved calculations, notes and settings.

The legal basis is Art. 6(1)(f) GDPR (legitimate interest in the secure operation of the website).

Cloudflare’s terms incorporate a data processing addendum for covered customer data. Cloudflare identifies customer logs and content transmitted through its network as examples of processing on a customer’s behalf. Cloudflare may act as controller for its own purposes.

Cloudflare may process operational records to deliver and protect the service. The country redirect function does not write logs of its own. We have no verified fixed deletion period covering all provider request records for this site. Cloudflare describes retention criteria including purpose and legal obligations.

Reports may include the requested URL and its parameters, the referrer and error details. Cloudflare says it uses the client IP to identify network characteristics and does not log it in this reporting pipeline. For evspendpure.com this function is switched off in the domain settings.

These hosting details apply to evspendpure.com and www.evspendpure.com. An online request requires connection data. Cookies and local settings

The calculator uses local browser storage for explicitly chosen settings and the history. New history links carry the entry identifier in the URL fragment (after the # character), which browsers do not send to the server. Historical links with the parameters id, entryKey or entryIndex remain supported; for them the identifiers may reach the hosting provider in the requested URL, and the page removes them from the address bar after opening successfully. These links do not embed calculator values or notes in the URL.

When the start page (/) or the history page (/verlauf) is requested, a server-side function (Cloudflare Pages Function) may use the country code determined by Cloudflare's IP geolocation (request.cf.country) to redirect to a matching language version: visitors from Türkiye to /tr/, visitors from most other countries to /en-eu/. Visitors from Germany, Austria, Switzerland and a few other countries stay on the default path. The function does not store the country code. No cookies are set in this step, and no locally stored calculator inputs are read or processed on the server.

Market and language are then determined in the browser from an explicit link parameter (market), the path of the opened language version (/tr/, /en-eu/), the browser language and an explicit choice in the in-app market selector, which is held in localStorage. Merely opening pages, switching language on legal pages and opening a history entry do not change that stored choice.

You can clear the website's localStorage via your browser's site settings. This also removes the calculations, notes and settings stored there. This deletion does not transmit additional calculator contents to the servers.
